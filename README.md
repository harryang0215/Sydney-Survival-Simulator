# Sydney Survival Simulator

## COMP9001 Final Project

Sydney Survival Simulator is a Python-based simulation game
designed for international students living in Sydney.

Players experience 30 days of student life while balancing
money, health, happiness, and academic progress.

## Features

- Interactive 30-day survival simulation
- Study, work, shopping, exploration, and rest
- Random events inspired by student life in Sydney
- Money, health, happiness, and study management
- Save and load game progress
- Multiple possible endings
- Input validation and error handling

## How to Run

1. Download all Python files.
2. Keep the files in the same folder.
3. Open a terminal.
4. Run:

```bash
python3 main.py
```

5. Follow the instructions displayed in the terminal.

## Requirements

- Python 3
- No external libraries required
- No internet connection required

## Python Concepts

This project demonstrates:

- Variables and data types
- Conditional statements
- Loops and functions
- Classes and objects
- Advanced flow control
- Exception handling
- File input/output
- Automated testing

## Testing

To run the automated tests:

```bash
python3 -m unittest test_game.py
```
